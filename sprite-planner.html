How to use: open a template strip in Krita (or any art app) as a guide layer, draw each frame on a new layer over it, hide the guide, and export as assets/sprites/<character>/<animation>.png. Refresh this page to check it.
  • Transparent background, same size as the template, frames left to right.
  • Draw facing right. Feet on the blue baseline, body centered on the dashed line.
  • The faint figure is the current puppet's pose, just for reference. Red = where that frame's attack hits. Blue dashed = where you can get hit.
  • Start with the start here animations. Anything you haven't drawn keeps using the puppet.
