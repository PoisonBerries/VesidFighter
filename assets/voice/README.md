# Voice lines

One folder per character. Drop audio files (mp3, ogg, wav or m4a) into that
character's folder:

    assets/voice/keenan/
    assets/voice/artur/
    assets/voice/carlos/
    assets/voice/nathan/
    assets/voice/owen/
    assets/voice/robert/
    assets/voice/ryan/
    assets/voice/sam/
    assets/voice/john/

Nothing plays yet. Once the files are in, say when each one should play
(for example: round start, taking a hit, using the special, winning) and the
game will be wired up to match.

Tips: keep each line short (a second or two), trim any silence at the start so
it lands on the action, and use descriptive file names such as
`special-1.mp3` or `win.mp3` so it's easy to say which is which.
