# Sprites

Open `sprite-planner.html` (served, e.g. `python3 -m http.server`) for the full
checklist, templates, and live previews of what you've drawn.

- Draw each animation as one PNG strip: `assets/sprites/<character>/<animation>.png`
- Same size as its template in `_templates/`, frames left to right, transparent background
- Face right, feet on the blue baseline, centered on the dashed line
- `_templates/` is regenerated by the planner and not committed to git

Frame lists come from `js/spritePlan.js`, which reads each move's timing from
`js/characters.js`, so changing a move's timing can change its frame count.
